# Sources

Every row on every page of this family comes from one of the addresses below.
Each was fetched by this machine on the date shown, with Python's own HTTP
client, no browser and no search engine. A refusal or a shell is recorded here
as what it was; none of them was worked around.

**Cadence:** weekly. `refresh.py` re-fetches every address, compares each quote
with the words on the page that day, and marks a row `drifted` when they differ.

## Terms: an open defect, and nothing has shipped

The build contract says: refuse to ship a source with no terms quote. Four of
the 18 sources we quote gave up a terms or copyright sentence to an
automated read; the rest did not, and typing one from memory would be exactly
the fabrication this estate exists to avoid. So the terms column below is
honest and incomplete, and this family is on a branch: nothing is pushed,
nothing is merged and no page of it is public. A person has to read the terms
on the remaining sites and fill this in before it is published.

* **DC** — https://dc.gov/page/terms-and-conditions-use
  > Copyright Pursuant to federal law, federal government-produced materials appearing on this site or elsewhere are not copyright protected.

* **NC** — https://www.ncleg.gov/disclaimer
  > Use of Photographs and Graphics Photographs and graphics on the North Carolina General Assembly Website may be under Copyright Protection.

* **WA** — https://leg.wa.gov/disclaimer/
  > Any user intending to obtain the Revised Code of Washington or the Washington Administrative Code for the purpose of selling the same is advised to contact the Washington State Statute Law Committee, which claims copyright for both codes, at (360) 786-6777 .

## What a refusal looked like

* **Connecticut, Illinois, Michigan** — the certificate chain could not be
  verified from this host, so the connection never opened. Recorded, not
  worked around.
* **Maine, Massachusetts, Mississippi, New Hampshire, Tennessee** — 404 at the
  address we hold. **Hawaii** — 403.
* **Texas, Indiana, South Dakota, Utah, Alabama, Alaska, Georgia, Louisiana** —
  the address answers 200 with an application shell: a page whose text is
  fetched by script after it loads. There is no statute text in what arrives.
  Texas matters most: the brief named it as the good fixture.
