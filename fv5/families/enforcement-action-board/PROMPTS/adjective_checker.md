# PROMPT — adjective checker (optional QA pass, second-pass door)

## This family sends NO prompt to write any page text

Every word on every board is either reproduced verbatim from EPA (the row fields)
or hand-written fixed copy in the slice module (section headings and the honest
notes about what EPA does and does not give us). **No page text is generated by a
model.** So there is no first-pass generation prompt to document, and nothing in
the build path calls any model door.

Because nothing is generated, the token budget file
(`~/.hermes/state/fv5/enforcement-action-board/tokens.jsonl`) records `0` tokens
per run. The 2,000,000-token cap in the contract is enforced in `refresh.py`
anyway, so the file is real from the first run.

## The one optional model use: flag adjectives in a page

S3 allows an optional checker that flags any adjective in generated text. Since we
generate none, this checker is a QA tool you can point at a built board to prove
the record-only rule held. It is NOT wired into `refresh.py` or the site build.

- **Model door (second-pass QA door):** `http://127.0.0.1:30004/v1/chat/completions`
  — OpenAI-style, model name `qwen38`, no auth. (The first-pass door
  `:30003` is unused here because there is no first pass.)
- **Input schema** (the checker is given only the text on the page; it is never
  asked for a fact it was not given):
  ```json
  {"page_id": "enforcement-action-board/<slug>", "text": "<the visible page text>"}
  ```
- **Output schema:**
  ```json
  {"adjectives": ["<word>", "..."], "verdict": "clean" | "has_adjectives"}
  ```
- **System prompt:**
  > You are a copy checker for a public-records page. You are given only the text
  > of the page. List every adjective that describes a company, a case, or a
  > penalty (opinion words such as "serious", "egregious", "massive"). Ignore
  > factual words that are part of a proper name, a statute, or a date. Do not add
  > any fact, name, number, or date that is not already in the text. Return JSON
  > matching the output schema and nothing else.
- **Checker (verify) pass:** run the same text and the first output back through
  `:30004` with this instruction, and keep a flagged word only if both passes
  agree:
  > Here is a page's text and a list of words claimed to be opinion adjectives.
  > For each word, answer keep or drop: keep only if the word is an opinion about
  > a company, case or penalty AND appears in the text. Return
  > `{"adjectives": [...], "verdict": "clean"|"has_adjectives"}` and nothing else.

Any run of this checker appends its token use to the budget file and stops if the
running total would pass 2,000,000.
