What this issold on the Apify Store

This is the shop-window for three small scrapers that live on the Apify Store, a marketplace that runs a program on its own servers and bills the person who runs it. You do not pay us here. The Store charges $0.50 to start a run and $0.005 for each record the run returns, takes its cut, and pays us the rest. Each scraper reads one free public source and hands back a clean table.

These read firms, facilities, water systems and incidents — never a private person. No operator's name, phone, email or home address is kept. Public records can lag their source, so a run is only as fresh as the agency's own file on the day you run it.

The three scrapers

  • OSHA severe-injury reportsEmployer, city, state, industry code, and whether a hospitalisation or amputation was reported. Source: the OSHA severe-injury page. That page returns a block (HTTP 403) to automated fetches from our test machine, so the run reads it from the buyer's Apify run and each item records which source it came from. No injured worker is named — the public file carries no such name and we keep none.
  • EPA drinking-water systemsOne item per public water system: its ID, name, town, people served, connections, water source, owner type, and its count of safe-drinking-water violations. Source: EPA Envirofacts SDWIS, which we can read live and in full. This is the sample below.
  • NRC spill noticesOne item per pollution incident reported to the National Response Center: date, state, town, material, medium and incident type. Source: the Coast Guard's NRC download, served through a form rather than a plain file, so the run drives that form. No caller is named.

What these do not do

  • No private peopleThe subject is always a firm, a facility, a water system or an incident. A row that read as a private individual would be withheld, not renamed.
  • No home addressesTown and state only. No street line is ever kept or returned.
  • No claim to be the agencyNot affiliated with OSHA, the EPA or the US Coast Guard. Not legal, tax or professional advice.
  • Only as fresh as the sourceEach record is read live from the agency on the day of the run, and public records can lag the event they describe.
