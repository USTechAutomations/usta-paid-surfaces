Doing this yourself

Every ISO publishes today’s queue and overwrites the last one. To get what moved you have to download each queue on the same day every week, keep the old copy somewhere you can still read it, and line up 6,691 projects across five different file layouts.

Miss one week and that week is gone. The ISO does not republish it, and there is no public archive to go back to. That is the whole reason this file exists.
