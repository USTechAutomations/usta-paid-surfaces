What this table would sayfrom the written plan · 2026-08-25

Public table of accredited calibration labs: who is accredited for what measurement in what range, with an "as at" date per row — derived facts only, never the register's document text

Those are the plan’s own words, read out of it as this page was built. The last part of them is the part that decides everything else: derived facts only. Who holds an accreditation, for what, over what range, on what day — never the register’s own documents, and never their text.

One whole pass, or none. 4,300 certificates at ten seconds each is a twelve-hour pass: publish whole-pass-or-nothing, "as at" date on every row. A half-finished pass would put some labs on the table and leave others off it with no way for a reader to tell which, and a table like that is worse than no table: it reads as a verdict on whoever is missing.

The crawl rules put nothing off limits and ask for a gap between requests, which is the gap the pass above is timed at. The host that actually serves the directory publishes no crawl rules at all, and its directory page carries no terms link, no privacy link and no copyright line anywhere in it. None of that is permission. A door nobody locked is not a door somebody opened.

The terms of use are generic website boilerplate. Counted over the whole page, these words appear in them no times at all: accredited, automated, crawl, data mining, directory, redistribute, republish, robot, scope, scrap. They neither forbid what this table would do nor grant it.

So three separate questions were asked, and they were given three different answers rather than one convenient one:

Why the register is not named on this page0 of 21 permission notes cover it

This estate has one bar for naming somebody else as a source on a public page: a written permission note about that address, kept on our own disk, whose verdict is that we may. Counted as this page was built, there is no such note for the register — and a page may not write itself one. That is somebody’s decision to make, and until it is made the page says “the register” and says why.

It is checked in both directions, on every build. The words that would name the register are worked out from the addresses in the saved licence file rather than listed in the code, the finished page is searched for them, and one hit stops the build. And the day a permission note for that address does appear, the reason above has stopped being true — so that stops the build too, until somebody rewrites this section to say what the note actually permits.

Nothing here is hidden from you: the file that records who the register is, what was fetched from it and when, is named at the foot of this page.
