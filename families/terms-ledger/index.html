What the $179 pack is

One evidence pack covers the sites you name. After you pay, the buyer receives the dated, quoted change-history, each line tied to a stored read and a fingerprint, plus the per-subject chain for those reads.

  • Quoted lines that appeared or disappearedEach line is copied from a stored read. We do not paraphrase it.
  • A fingerprint and a read time on every lineThe fingerprint is a seal over the stored bytes. If those bytes were rewritten, the seal would not match.
  • A chain per site-and-fileEach new stored read is linked to the one before it. If a stored read is dropped or skipped, the chain no longer verifies. That is what “no read was removed” means here.
  • A safe answer when we cannot claim a changeOne read is not two dates. Two reads with the same bytes are not a change. We say so, and we still quote what we hold.

If you want us to keep reading those same sites, a $199 per month watch is quoted in the email thread, not on this page’s price rail.

What the chain proves11 links across 6 subject chains in the fixture run

Each stored read already carries a fingerprint, so we can prove that read was not rewritten. That is not the same as proving a read was not taken out. The pack now also carries a hash chain per site-and-file: the first read hangs off a fixed start value, and each later read is linked to the tip before it. The prototype checks that chain. Appending a read extends it. Deleting a stored read fails the check. Skipping a stored read fails the check.

This is our own seal, not a court affidavit. A third party has not witnessed these hashes. Do not treat this pack as proof that would stand up in court. Do not treat it as a complete archive of the live web. It proves two things about the reads we stored for the sites in the pack: those reads were not rewritten, and no stored read was removed.
