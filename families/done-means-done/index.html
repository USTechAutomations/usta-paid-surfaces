What this is

This is an Atlassian Forge app for Jira Cloud. It reads a ticket and lists what would stop a stranger from knowing the work is finished. The 7 Sep 2026 demo lint of 15 fixture tickets found 15 primary issue rows. That file is a demo, not a live Jira site.

Every number on this page is a demo output labeled as a demo. The app never edits a ticket. It never blocks a workflow unless a project admin turns blocking on.

What it lints

  • No acceptance criteriaNothing a tester could tick off.
  • Vague finish words"works", "looks good", "done when done".
  • No observable testNo Given/When/Then, no status to read, no count to check.
  • Scope words"etc", "and so on", "various".
  • Description under 25 wordsToo short to say what changed.
  • No estimateNo original estimate and no story points.
