Grant Fit privacy policy

Privacy policy — Grant Fit

How Grant Fit handles your page text, organization profile and saved key.

View current product status

Updated 13 September 2026 UTC. This notice distinguishes the public 0.1.0 extension from the prepared 0.1.3 update.

Analysis is currently unavailable

Grant Fit does not currently provide a usable grant assessment service or a paid offer. The public Chrome listing still carries version 0.1.0. A 0.1.3 package has been uploaded as a draft; that upload has not changed the public listing.

Do not enter a license key or send confidential page or organization information while analysis is unavailable.

What public version 0.1.0 reads and sends

When you click Check this page, version 0.1.0 can read the active tab and attempt an analysis request even though the service is unavailable. It extracts up to 40,000 characters from that page. It does not scan other tabs or automatically scan the pages you visit.

The analysis request includes the extracted page text, your saved organization profile and a hashed installation identifier. It does not include the tab address or title as separate fields; either may still appear within the extracted page text. A saved license key may also be sent. Normal connection information, such as an IP address, reaches the receiving service.

Version 0.1.0 checks a license key with the entitlement service using a request address that contains the key. Its developer settings can change the destination services. Avoid entering a key or changing those destinations. A failed analysis request does not prove that no information was transmitted.

The profile, installation seed, usage counter, saved key and previous verification cache are stored in Chrome local storage in this browser. Saving a profile alone does not send it to a server. A cached key check is not an offline report: analysis requires a responding service.

What prepared version 0.1.3 changes

The 0.1.3 draft requests storage permission only. Its analysis hold rejects a request before reading a funding tab or contacting an analysis service. You can save, edit and remove your organization profile locally. It cannot verify a new key; a previously saved key and its verification cache can be removed locally without displaying the key.

This draft ignores saved developer endpoint overrides. Existing local usage and request records may remain until the extension is uninstalled. The draft is not a released analysis service, and this notice does not claim that public version 0.1.0 has acquired these protections.

Your data controls

Use the profile controls in the version you have installed to edit your local organization information. Version 0.1.3 adds an explicit remove action. Uninstalling Grant Fit removes its extension-local storage. Removing a key does not cancel a subscription.

Local editing, removal or uninstalling does not confirm deletion of information already sent to a service. For questions about earlier requests or a previously purchased key, contact operations@ustechautomations.com. Do not include a license key or confidential grant information in your initial message.

Grant Fit does not use the page text to contact a funder or submit an application. It does not promise an award. Before a future analysis release, this notice will need to describe the accepted service and its data handling.
