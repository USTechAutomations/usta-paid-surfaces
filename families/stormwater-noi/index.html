Texas requires a construction stormwater notice of intent before ground is broken on a site that disturbs an acre or more. TCEQ issues the authorization (number starts TXR15). TCEQ's own search did not answer from this box on 6 Sep 2026, so this copy is the federal ICIS file of those same authorizations, published by EPA. We hold one sealed copy so far (6 Sep 2026). Until a second copy exists, the weekly file is notices whose filing date on this copy falls in the seven days before that copy date. After the second copy, the file is the set difference.
