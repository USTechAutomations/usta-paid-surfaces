What this page cannot tell you

  • An agent-instructions file tells an assistant what to say about a shop. It is not a checkout. A company can serve one and still have no way for a robot to buy anything.
  • A server answering 200 is not proof of a file. We count a file as there only when the body we saved really is that kind of file. On 23 Aug 2026 that test threw out 156 answers of 200 across 40 companies whose servers handed back a web page instead.
  • On 23 Aug 2026 we could not read one or more files at 84 of the 276 companies, because the server refused us, rate-limited us, timed out, or its robots.txt told us not to fetch. Those are shown as cannot tell. We never count a refusal as the file being gone.
  • The panel is a fixed list of 276 company websites, frozen before collection started. A company that is not on that list is not missing from this feed — we have never asked it anything. Email operations@ustechautomations.com with the companies you follow and we will tell you which of them we already hold.
  • Our first read is 11 Jun 2026. A file already up that morning shows a first seen date of 11 Jun 2026, and we cannot tell you how long it had been there before we started looking.
  • We compare the bytes of the file, not its meaning. A company that stamps today's date inside its file shows up as changing it every day, and the table says so rather than selling you the churn as news.
  • There are 7 days in the window with no read at all: 19 Jun 2026, 4 Jul 2026, 15 Jul 2026, 8 Aug 2026, 18 Aug 2026, 19 Aug 2026, 20 Aug 2026. Where a file appeared across one of those gaps we give the two dates we actually hold, never a guessed one in between.
