What this cannot tell you

It is not a forecast and it is not advice. It does not say how long your file will take. It says how long the files we watched did take.

Austin and San Francisco clocks are not date-submitted to next. No application-submitted timestamp is stored for these boards. Only Montgomery has a stored intake status (Open).

This is not the Metro File and not the city board dump. Those are different products. This SKU is the clock number plus hours, not every status-change row and not the raw board table.
