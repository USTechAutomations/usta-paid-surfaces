What this is

This is a free WordPress plugin plus a hosted weekly scan of the public pages we can fetch. It is not a legal certificate, not an overlay widget, and not a guarantee that a site meets any guideline. The 6 Sep 2026 demo scan of our own /feeds/ pages found 107 issue rows across 40 pages. We hold 1 sealed weekly snapshot so far.

Automated checks find some of the issues the guidelines describe, not all. A person still has to read the file. We do not log in, we do not store personal data, and we do not change how the front of a site looks.

Get the free pluginGPL-2.0, no key

The plugin is free software under GPL-2.0. It adds a Tools screen that checks the site's own front page, or any URL on the same site you type. Every check runs with no key. A listing on wordpress.org is pending review, so until that lands you can install the zip.

  • Download the 0.1.0 plugin zipInstall it on a WordPress site you own. Tools → Accessibility scan. The hosted-scan link is a checkbox, off by default, and the plugin never calls our servers.

What the weekly scan checks

  • Images without alt textAn img tag with no alt attribute.
  • Empty links and empty buttonsNo visible text and no aria-label.
  • Form fields without a labelNo for/id pair, wrapping label, or aria-label.
  • Missing lang on the html tagScreen readers need to know the language.
  • Heading level skipsAn h1 followed by an h3, for example.
  • Duplicate idsTwo elements sharing one id.
  • Low-contrast inline coloursOnly where both text colour and background are set and can be read as numbers. Ratio below 4.5 to 1 is flagged.

Automated checks find some of the issues the guidelines describe, not all. We do not run a browser overlay. We fetch public HTML, obey robots.txt, and write a file.
