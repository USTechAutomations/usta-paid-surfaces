What this cannot tell you

It does not reprint any site file. It does not quote a robots line. Quoting a robots line is UNKNOWN for sale. We never quote another site's robots text.

It does not say what GPTBot or ClaudeBot was allowed to do. That would need a robots line. We do not swear to what the site intended. We swear to our fetch record.

It is not a statement about a tool we did not send. The named tool on these rows is the one whose user-agent token is closing-web-clock/1.0.

It is not a feed. One oath per named day, paid each time. There is no next month's file unless you buy again.

A 403 is only that our tool was refused. A 404 is only that this path did not return a file to us that day. Neither is a reading of the site's rules.

This is not a lawyer opinion. We believe swearing to our own fetch needs no site's permission. That is not a legal opinion. We did not get a lawyer to confirm it.
